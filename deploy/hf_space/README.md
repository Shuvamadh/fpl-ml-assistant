# FPL ML Assistant

A shareable FPL (Fantasy Premier League) assistant built around LightGBM
predictions, live squad/transfer recommendations, and mini-league insights.
Runs entirely server-side -- everyone visiting the Space gets the same live
data pull, no login required. Use the "Viewing as" picker to see the app
built around any manager's own squad.
